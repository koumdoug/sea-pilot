# Lancement organique FreelanceNexa — checklist et mesures

Rien de ce qui suit n'a été exécuté : aucune publication, aucun message, aucune dépense.

## Avant d'envoyer du trafic (bloquants)
1. Dans SEA Pilot : fiche FreelanceNexa → « Créer la landing page » → relire les textes (brouillon), **publier**.
2. Côté produit (hors SEA Pilot) : publier des pages **confidentialité et conditions** ; relier `freelancenexa.com` (README du produit) ; confirmer le **prix et la devise** dans Stripe avant d'afficher un tarif.
3. Mentionner l'essai de 30 jours sur la page d'inscription du produit seulement si c'est exact en production.
4. Vérifier le parcours réel inscription → essai → paiement par l'équipe du produit (non vérifié ici).
## Diffusion (humaine, sans automatisation)
- Utiliser des liens avec UTM (`utm_source`, `utm_medium=organic`, `utm_campaign`) pour chaque publication ou message personnel.
- Contenus : utiliser « Préparer un brief de contenu » sur la page ; aucune donnée de mots-clés n'est fournie par SEA Pilot.
## Mesures des premiers résultats (par produit, 7/30/90 jours)
Visites → leads (par source UTM) → leads qualifiés → inscriptions → essais → paiements → revenus (par devise). Les conversions sont **saisies à la main** tant que l'intégration (contrat ci-joint) n'existe pas ; elles sont alors étiquetées « saisie manuelle ».
Première lecture utile : nombre de leads par source ; taux visite → lead seulement au-delà de quelques dizaines de visites.
